Features

Tudo que você precisa, já configurado

Do bootstrap inicial ao dia a dia — o AI Dev Kit cobre cada ponto de contato entre você e a IA.

🛡️

Auditor em tempo real

Intercepta toda escrita de arquivo via PreToolUse hook. Bloqueia SQL Injection, secrets hardcoded, endpoints sem autenticação antes de chegar no disco.

📄

CLAUDE.md gerado

Lê pom.xml, package.json e estrutura do projeto. Gera um contexto preciso e específico — não boilerplate genérico.

⚡

Compile & type check

PostToolUse hook roda ./mvnw compile após cada .java e tsc --noEmit após cada .ts. Erros aparecem na hora.

🚀

Smart Commit

Revisa o diff via IA, bloqueia se encontrar problemas, gera mensagem Conventional Commit automaticamente e faz push.

⌨️

Slash Commands

Comandos prontos e específicos para o seu stack: /project:endpoint, /project:test, /project:secure, /project:migration.

📋

Regras customizadas

Defina as regras do time em .aikit-rules.yml com padrões regex, severidade e mensagem. O auditor as aplica automaticamente.

Como funciona

Um comando. Tudo configurado.

O ai-kit init analisa o projeto e configura cada peça automaticamente.

0

Pre-flight

Verifica claude CLI, git e python3.

1

Detecção de stack

Lê pom.xml, package.json, angular.json. Detecta 20+ características do projeto.

2

Gera CLAUDE.md

Usa claude -p para gerar contexto real — arquitetura, convenções, comandos de teste.

3

Configura hooks

Escreve o .claude/settings.json com todos os hooks mapeados para o stack detectado.

4

Instala comandos

Só os comandos relevantes para o seu stack — sem poluição desnecessária.

5

Deploy do Auditor

Copia os scripts de hook e faz self-test para garantir que está funcionando.

Regras de qualidade e segurança

14 regras prontas para Java, Angular, React e qualquer arquivo. Extensíveis via .aikit-rules.yml.

IDSeveridadeDescrição
J-001CRITICALSQL Injection por concatenação de string em queries
J-002HIGH@RestController sem @PreAuthorize em nenhum endpoint
J-003MEDIUMSystem.out.println em código de produção
J-004HIGH@Transactional em método privado (sem efeito no Spring AOP)
J-005MEDIUM@Entity JPA sem equals/hashCode adequado
J-006CRITICALJWT secret hardcoded no código fonte
IDSeveridadeDescrição
F-001LOWconsole.log em código de produção
F-002MEDIUMTypeScript any explícito
F-003HIGH.subscribe() sem takeUntilDestroyed ou unsubscribe — memory leak Angular
F-004CRITICALSecret em environment.ts, .env ou arquivo de config frontend
IDSeveridadeDescrição
U-001CRITICALHardcoded password, token, API key ou chave privada
U-002LOWTODO / FIXME em código novo

Defina regras do seu time em .aikit-rules.yml na raiz do projeto:

yaml — .aikit-rules.yml
rules:
  - id: C-001
    severity: HIGH
    files: "*.java"
    pattern: 'System\.exit\('
    message: "System.exit() não deve ser usado. Lance uma exceção."

  - id: C-002
    severity: MEDIUM
    files: "*.tsx,*.ts"
    pattern: '^\s*fetch\s*\('
    message: "Use o hook useApi() em vez de fetch() direto."

Campos: id, severity (CRITICAL/HIGH/MEDIUM/LOW), files (glob), pattern (regex grep -P), message

Instalação

Pronto em minutos

Requisitos: Claude Code CLI, bash (Git Bash no Windows), python3, git.

1

Clone o repositório

git clone https://github.com/jeffev/ai-dev-kit.git
2

Rode na raiz do seu projeto

cd meu-projeto
bash /caminho/para/ai-dev-kit/ai-kit.sh init
3

Abra o Claude Code

claude
# SessionStart mostra status git + Docker
# Auditor ativo em toda escrita de arquivo
4

Use o Smart Commit no lugar do git commit

git add .
bash smart-commit.sh --push
💡 Sugestão: adicione um alias no seu shell para usar de qualquer projeto: 
# ~/.bashrc ou ~/.zshrc
alias ai-kit="bash /caminho/para/ai-dev-kit/ai-kit.sh"

# Uso:
ai-kit init
ai-kit commit --push
ai-kit audit-test src/main/java/MinhaClasse.java
