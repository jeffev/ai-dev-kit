Features

Everything you need, already configured

From initial bootstrap to daily work — AI Dev Kit covers every touchpoint between you and the AI.

🛡️

Real-time auditor

Intercepts every file write via PreToolUse hook. Blocks SQL Injection, hardcoded secrets, unauthenticated endpoints before they hit disk.

📄

Generated CLAUDE.md

Reads pom.xml, package.json and project structure. Generates precise, project-specific context — not generic boilerplate.

⚡

Compile & type check

PostToolUse hook runs ./mvnw compile after each .java and tsc --noEmit after each .ts. Errors surface immediately.

🚀

Smart Commit

Reviews the diff via AI, blocks if issues are found, generates a Conventional Commit message automatically and pushes.

⌨️

Slash Commands

Ready-to-use commands tailored to your stack: /project:endpoint, /project:refactor, /project:debug, /project:pr and more.

📋

Custom rules

Define your team's rules in .aikit-rules.yml with regex patterns, severity and message. The auditor applies them automatically.

🔔

Desktop notifications

Build failures trigger a native notification on Linux (notify-send), macOS, and Windows — so you know immediately without watching the terminal.

📊

Audit report

Run ai-kit audit-report to generate a markdown summary of all auditor findings — grouped by severity with rule, file, and line.

🩺

Doctor & Update

ai-kit doctor diagnoses your installation. ai-kit update refreshes hooks and commands in-place — no need to re-run init.

How it works

One command. Everything configured.

ai-kit init analyzes your project and sets up each piece automatically.

0

Pre-flight

Verifies claude CLI, git and python3.

1

Stack detection

Reads pom.xml, package.json, angular.json. Detects 20+ project characteristics.

2

Generate CLAUDE.md

Uses claude -p to generate real context — architecture, conventions, test commands.

3

Configure hooks

Writes .claude/settings.json with all hooks mapped to the detected stack.

4

Install commands

Only the commands relevant to your stack — no unnecessary clutter.

5

Deploy Auditor

Copies hook scripts and runs a self-test to confirm everything is working.

CRITICAL / HIGH
Write is blocked. Claude Code sees the error and must fix the issue before retrying. No bad code ever reaches disk.
MEDIUM
Write proceeds, warning is printed. Logged to audit.log. Smart Commit will highlight open warnings before committing.
LOW
Logged silently to audit.log. Visible in ai-kit audit-report and in the session-start summary.
Smart Commit gate
Blocks commit if open CRITICAL/HIGH findings exist today. Sends the full diff to Claude for secrets, SQL injection, and unprotected endpoints review.

Define your team's rules in .aikit-rules.yml at the project root:

yaml — .aikit-rules.yml
rules:
  - id: C-001
    severity: HIGH
    files: "*.java"
    pattern: 'System\.exit\('
    message: "System.exit() must not be used. Throw a proper exception instead."

  - id: C-002
    severity: MEDIUM
    files: "*.tsx,*.ts"
    pattern: '^\s*fetch\s*\('
    message: "Use the useApi() hook instead of calling fetch() directly."

Fields: id, severity (CRITICAL/HIGH/MEDIUM/LOW), files (glob), pattern (regex grep -P), message, fix (optional — appended to the auditor message)

To suppress built-in rules project-wide, add them to .aikit-ignore:

text — .aikit-ignore
# one rule ID per line — # starts a comment
F-001  # uses custom logger wrapper, no console.log needed
U-002  # TODOs tracked in Linear
Installation

Ready in minutes

Requirements: Claude Code CLI, bash (Git Bash on Windows), python3, git.

1

Clone the repository

git clone https://github.com/jeffev/ai-dev-kit.git
2

Run from your project root

cd my-project
bash /path/to/ai-dev-kit/ai-kit.sh init
3

Open Claude Code

claude
# SessionStart shows git + Docker status
# Auditor active on every file write
4

Use Smart Commit instead of git commit

git add .
bash smart-commit.sh --push
💡 Tip: add a shell alias to use it from any project: 
# ~/.bashrc or ~/.zshrc
alias ai-kit="bash /path/to/ai-dev-kit/ai-kit.sh"

# Bootstrap & maintenance
ai-kit init
ai-kit update           # update hooks in-place
ai-kit doctor           # diagnose installation

# Daily workflow
ai-kit commit --push
ai-kit audit-report     # generate findings report
ai-kit audit-test src/main/java/MyClass.java
